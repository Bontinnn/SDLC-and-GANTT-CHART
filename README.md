🌍 Project Title
<h2 align="center">✨ EMPOWERING YOUTH GOVERNANCE: <br> ENHANCING BUDGETING AND TRANSPARENCY SYSTEM FOR <br> SANGGUNIANG KABATAAN USING GEOFENCING IN ZONE-8 BULAN, SORSOGON ✨</h2>
📖 Description

This system helps the Sangguniang Kabataan in Zone-8, Bulan, Sorsogon become more transparent and accountable in handling projects and budgets.

🔹 By using geofencing, it makes sure funds are used properly within the community and activities are monitored.
🔹 It aims to build trust, encourage youth participation, and improve local governance.
